# axcend_flutter_task

A Flutter Project developed in dart that retrieves data from JSONPlaceholder API then displays the data onto the mobile page achieving the functionality set out in the task description. 
Includes 7 tests for the UI widgets and the API logic using MockClient.


Improvements would include:
1. Search Features to filter through users and tasks
2. More extensive testing
3. UI improvements to include more data from the json

How to Run:
1. flutter pub get
2. flutter run
3. flutter test
